# Figures

`original/` preserves the existing manuscript assets without modifying their bytes.
Their source hashes are recorded in `docs/migration-root.json`.

| File | Role |
|---|---|
| `task.pdf` | Task sequence |
| `cnn_architecture.pdf` | Network architecture |
| `neuro_results.pdf` | GLM and Searchlight surface rendering |
| `layercam.pdf` | Low/high preference spatial maps |
| `macroregion_enrichment.pdf` | Original five-group regional chart |
| `supplementary_roi.pdf` | Original top-five ROI chart per group and class |
| `regional_means.pdf` | Corrected compact regional layout from the current manuscript baseline |
| `rq3_global_mean_replacement_performance.pdf` | Input-replacement performance |
| `haufe_layercam_top20_dice_matrix.png` | Haufe/Layer-CAM spatial overlap |

The historical regional filenames and embedded E labels are retained for provenance.
New table-driven plots use **Mean Layer-CAM value (whole-brain mean = 1)**.
Run `python scripts/reproduce_figures.py` to regenerate statistical charts into
`outputs/`; see `docs/results.md` for their data and exact filenames. The task,
architecture and surface-rendered assets are not claimed to be regenerated by
that command.

The manuscript's current regional reference is the group-first normalization
used in the preserved regional figures, with the original five-group mapping.
The compact regional layout is an alternative presentation of those data.

`reproduced/` contains inspected snapshots of the seven table-driven charts, their captions, and source table mapping. Reruns continue to write to `outputs/figures/`.
