# Figures

Follow [figure reproduction](../docs/README.md) for commands, output filenames, and links to the original brain-map PDFs.

- `reproduced/` contains ready-to-use PNG and PDF result charts.
- `original/` contains the original manuscript figures, brain surface renderings, and task/model diagrams.
- New charts are written to `outputs/figures/` by `python scripts/reproduce_figures.py`.

For the decoding task, evaluation protocol, and numerical results, see [decoding results](../docs/results.md).
