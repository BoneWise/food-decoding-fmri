# Local data

The source is **A densely sampled fMRI dataset for investigating food valuation** by Sugawara and colleagues: [OpenNeuro ds007267](https://openneuro.org/datasets/ds007267), [data descriptor](https://doi.org/10.1038/s41597-026-07323-y), and [authors' analysis repository](https://github.com/szkshnsk/A-densely-sampled-fMRI-dataset-for-investigating-food-valuation).

Place local imaging data and generated beta maps under this directory. The MATLAB scripts in `preprocessing/` estimate beta maps from prepared fMRIPrep derivatives using SPM25. Input paths and model commands are listed in the [decoding configurations](../configs/decoding/README.md).

For the included result charts, follow [figure reproduction](../docs/README.md); the required result data are already in the repository.
